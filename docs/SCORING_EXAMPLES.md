# Qualification Review Examples

These are synthetic cases for reviewing judgment, not real candidate records. Test the interpretation, not a predetermined total score.

| JD clause and profile evidence | Correct interpretation | Avoid |
| --- | --- | --- |
| CPU OR GPU product experience; candidate owns CPU products | Required alternative met; assess actual work separately | Deducting for missing GPU ownership on that same clause |
| Working knowledge of accelerator architecture; candidate has adjacent systems work | Assess requested knowledge depth | Inventing mandatory prior accelerator product ownership |
| Engineering degree; MBA preferred; both supported | Credit the explicit MBA preference even without a preferred heading | Inventing additional specialist preferences |
| Four distinct preferences: two met, two missing | Half coverage; use B band, no below-half domain cap | Automatically capping because the company is competitive |
| Complete JD has no preferences | B=15 default, explicitly labeled convention | Treating absent preferences as all met or all missing |
| Same missing API-platform ownership repeated twice | One substantive gap | Two deductions for synonymous wording |
| Separate required optical expertise and production diagnostics both missing | Separate evidence-backed deductions can apply | Collapsing genuinely independent requirements |
| Coursework/personal project relevant to applied AI | Credit actual work and literacy | Claiming production deployment or dismissing all AI evidence |
| Literal alternative met but product domain still unrelated | Keep eligibility credit; assess domain honestly | Automatic Apply or automatic pivot ceiling |
| Required skill gaps produce A<=15 | Skip; do not rescue with strategic interest | Exception merely because the company is attractive |

Keep a compact calculation in the receipt, not a worksheet in every user-facing lead. Original evidence takes precedence over an earlier review's score.
